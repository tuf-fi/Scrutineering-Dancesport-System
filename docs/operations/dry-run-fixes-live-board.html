BOSS · 21 November 2026 · New public page

Live board

A new public page that shows what is on the floor, what is next and what is still to come. Tapping a round opens its heats as back number chips, the same as the compere's heat list. A visitor can type a back number to see only that athlete's remaining rounds.

What the page shows

PartWhat it does
NavbarLive board sits between Competitions and Bicol Athletes. It opens the competition held today. When there is none, it says No ongoing competition.
On the floor / Up nextThe same black panel as the public program page. It refreshes by itself as the scrutineer moves the day along.
Find a back numberType a back number to list only the rounds that number still has to dance.
Coming upThe next 10 unfinished rounds, each its own bordered block with status circle, start time, event, round and action. Tap a block to open Heat 1, Heat 2, ... with the back numbers in each (a single heat reads All entries, a final Finalists).
Full programA button that opens the complete running order. The public program page no longer has Print or PDF buttons.

How to test

  1. Open Live board in the navbar. On a competition day it opens that day's board; otherwise it says No ongoing competition.
  2. Under On the floor, the current and next rounds show in the black panel.
  3. Tap a round under Coming up: its heats open with the back numbers. Tap again to close.
  4. Type a back number: the list narrows to that number's remaining rounds.
  5. Check the page at phone width (390px) and on a laptop (1280px).

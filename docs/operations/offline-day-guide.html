Running BOSS offline

A guide for the people who set up and run the venue laptop. You do not need to be technical. Follow the steps in order and tick each one.

What this is

Normally everyone uses BOSS over the internet. If the venue has no signal and no Wi-Fi, we run the whole competition from one laptop and a small Wi-Fi router that does not need internet. Phones, staff laptops and the compere's screen all connect to the router. Everything works the same as online.

When the competition is over, we save the day into one file and load it back on the online BOSS website. The results then show on the public site.

Before the eventOn the dayAfter the event
Admin hands the competition to the laptop. Helper puts it on the laptop and tests it. Everyone joins the router's Wi-Fi and uses BOSS as usual. Admin saves the day to a file and loads it on the online website.
Practise first. Do the whole thing once, a few days before, with the real router and a few real phones. The software has been tested, but this setup has not yet been tried with a real router and real phones. Your rehearsal is the first real check, so write down anything that does not match this guide.

What you need

  • One laptop (Windows) with Docker Desktop installed (a one-time job for whoever sets it up). Plugged in all day, set never to sleep, with the correct date and time.
  • One Wi-Fi router. It does not need internet. Ask whoever set up the laptop to reserve the same address for it, and to switch off “client isolation”. Without that, phones cannot reach the laptop.
  • One USB drive that stays plugged into the laptop. BOSS saves a copy of every change onto it.
  • A second laptop as a spare, set up the same way.
  • Printed paper: heat lists, recall lists and blank mark sheets from the Printouts page. If everything fails, the competition can still go on paper.
  • The secret code (called DATA_KEY) from the admin. The admin keeps it private and gives it only to the person setting up the laptop.

Part 1 · A few days before

The admin, on the online BOSS website

  1. Sign in as Admin. In the menu choose Offline day.
  2. Find the competition. Press Start offline day, then Hand it over.
    You should see: the competition now says “Venue laptop, since…” with today's time.
    From now on, changes to the competition are paused online. Secretariat and staff cannot change entries or rounds, and teams cannot send new entry requests, until the day is loaded back. Finish registrations and payments before you do this.
  3. Press Download database copy (top right). A file called bis-venue-copy.db is saved.
    Keep this file private. It contains every account. Do not email it. Hand it over on a USB drive or a private folder, and delete it from anywhere else when done.

The helper, on the venue laptop

  1. Open Docker Desktop and wait until it says it is running.
  2. Open the folder deploy, then venue. Put the file bis-venue-copy.db in it.
  3. Double-click setup.bat. A black window opens. It asks three things, one at a time:
    • Type YES and press Enter (this puts the copy on the laptop).
    • Paste the secret code from the admin and press Enter.
    • Type the USB drive letter, for example E, and press Enter.
    You should see: after a few minutes, “BOSS is running” and one or more addresses like http://192.168.1.50. Write down the address. That is what everyone will type.
  4. Turn on the router. Join its Wi-Fi with a phone. In the phone's browser type the address, then /api/health, for example http://192.168.1.50/api/health.
    You should see: words that include "status":"ok" and "mode":"venue".
  5. On the laptop, open the same address (without /api/health). Sign in as Admin. Choose Adjudicators and panels then Print PIN cards and print them from this laptop.
    Cards printed from the online website will not work at the venue. Only cards printed from the laptop do.

Practice round (do not skip)

  • Run one round: start it, mark on three phones, approve it, publish it.
  • Check the compere's screen shows it (/compere after the address).
  • Unplug the router for one minute while marking. Plug it back in. The phones should keep their marks and send them by themselves.

After a practice, ask the admin to press Take back on the Offline day page so the competition is not stuck. Then start again properly when it is real.

Part 2 · On the day

  1. Plug in the laptop and the router. Make sure the laptop does not sleep and the lid stays open.
  2. If the laptop was restarted, double-click start.bat. Everything is kept exactly as it was.
  3. Plug in the USB drive.
  4. Tell everyone to join the router's Wi-Fi (not mobile data) and type the address. Put it on a sign.
WhoTypes this (after the address)
Admin, secretariat, scrutineer, chairperson/staff-access
Compere (the big screen)/compere
AdjudicatorsScan the QR code on their PIN card, or type /adjudicator

If something goes wrong

What happensWhat to do
A phone cannot open the addressCheck it is on the router's Wi-Fi and not mobile data. Check you typed the address exactly, with http:// at the start.
The router loses powerPlug it back in. Adjudicator phones keep their marks and send them again. Staff screens say “Offline” until it is back.
A staff screen says “Offline”Wait a moment. If it stays, check the laptop is awake and the router is on.
The laptop shuts down or breaksUse the spare laptop: plug in the USB drive, open deploy\venue, double-click restore.bat, type the drive letter. It starts from the newest backup. Then tell everyone to reload their page.
Nothing works at allUse the printed paper sheets. Enter the marks into BOSS later.
An adjudicator's PIN is refusedCheck the laptop's date and time are correct. Use a PIN card printed from the laptop.
Never run setup.bat during the event. It erases the laptop and starts again from the copy. To restart, always use start.bat.

Part 3 · After the event

The admin, on the venue laptop

  1. Make sure the last round is approved and the results are final.
  2. Open the laptop's address, sign in as Admin, choose Offline day.
  3. Press Download day file next to the competition. A file with bis-day in its name is saved.
    Copy it to a USB drive and keep a second copy. This file is the whole day.

The admin, back online

  1. Sign in to the online BOSS website as Admin. Choose Offline day.
  2. Next to the competition press Load day file, then Choose the file and pick the file you saved.
    You should see: “The file is fine” and a list of what it holds (rounds, marks, results…). Nothing has been changed yet.
  3. Check the numbers look right, then press Load it.
    You should see: “The day is loaded”, and the competition goes back to “Online”. The results and rankings now show on the website.
  4. Check one result on the public site. Then stop the venue laptop (double-click stop.bat) and delete bis-venue-copy.db from it.

If the laptop was lost or never used

On the online website, Offline day, press Take back next to the competition and confirm. The competition goes back to normal. Nothing from the laptop is loaded.

If the file is refused

The message saysWhat to do
“This is not a BIS competition day file”You picked the wrong file. Choose the one with bis-day in its name, not bis-venue-copy.
“Different versions of BIS”The laptop and the online website are not on the same version. Ask the person who set up the laptop.
“This competition is not with a venue laptop”It was taken back. Press Start offline day first, then load again.
